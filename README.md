# Hotel Costa Azul — Unidad 3

## Contenido
- `docs/Informe_Arquitectura_Hotel_Costa_Azul_79_paginas.pdf`: informe paginado con diagramas.
- `docs/Informe_Arquitectura_Hotel_Costa_Azul_79_paginas.docx`: versión editable.
- `docs/Matriz_Trazabilidad.md`, `docs/ADR.md`, `docs/Bitacora_IA.md`.
- `diagrams/src/`: fuentes PlantUML y Graphviz.
- `diagrams/exports/`: diagramas PNG/SVG listos para insertar.
- `src/`: código base inicial.
- `tests/`: pruebas iniciales.

## Ejecutar pruebas
Desde esta carpeta: `python -m unittest discover -s tests` (o `py -m unittest discover -s tests` en Windows).

## Importante
Este es un borrador académico basado en los documentos originales de Unidad 2 y la guía de Unidad 3. Revisar con el equipo los hallazgos pendientes, ejecutar las pruebas, completar la bitácora con el historial real de IA y subir los archivos al repositorio requerido. No se implementa base de datos ni aplicación de producción.
